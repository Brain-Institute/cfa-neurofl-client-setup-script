# neurofl-client-setup
## NeuroFL Client Setup  One-command setup for NeuroFL federated learning client nodes. Works on Linux, macOS, and Windows (WSL).  
### Quick Start  ```bash curl -sSL https://raw.githubusercontent.com/&lt;your-org>/neurofl-client-setup/main/setup-client.sh | sudo bash ```  See [CLIENT_NODE_SETUP.md](CLIENT_NODE_SETUP.md) for full instructions.
